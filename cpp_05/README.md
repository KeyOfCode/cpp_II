# C++ Module 05

This module covers exceptions, class inheritance, and abstract classes through a bureaucratic form system.

## Exercises

- `ex00`: `Bureaucrat` and grade validation.
- `ex01`: Signed forms and permission checks.
- `ex02`: An abstract `AForm` with concrete shrubbery, robotomy, and presidential pardon forms.
- `ex03`: Adds an `Intern` that creates forms by name.
